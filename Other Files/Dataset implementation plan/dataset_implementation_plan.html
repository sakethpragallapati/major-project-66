3. Runtime Knowledge Base vs. Golden JSON Architecture

A critical architectural distinction is made between Runtime Knowledge Bases and Evaluation Benchmarks:

  • Runtime Knowledge-Base CSVs: External dictionaries and vector databases that AI agents query during live execution (e.g., searching for clause wording, checking ICD-10 validity).
  • Golden Dataset JSONs: Self-contained evaluation cases containing both the input prompt/documents and the expected ground truth used by DeepEval to grade the system.

7. DeepEval Code Harness & Execution Blueprint

Below is the concrete implementation harness using deepeval to run component and pipeline evaluations:

import json
from deepeval import evaluate
from deepeval.metrics import (
    ContextualPrecisionMetric,
    ContextualRecallMetric,
    FaithfulnessMetric,
    GEval,
)
from deepeval.test_case import LLMTestCase, LLMTestCaseParams

# -------------------------------------------------------------
# 1. Custom G-Eval: Toulmin Logical Argumentation Soundness
# -------------------------------------------------------------
toulmin_argument_metric = GEval(
    name="Toulmin Argumentation Soundness",
    criteria=(
        "Evaluate whether the reasoning correctly establishes that an exception defeats the policy exclusion. "
        "The conclusion must logically flow from the grounds and warrant without contradictions or ungrounded assumptions."
    ),
    evaluation_params=[
        LLMTestCaseParams.INPUT,
        LLMTestCaseParams.ACTUAL_OUTPUT,
        LLMTestCaseParams.RETRIEVAL_CONTEXT,
    ],
    threshold=0.85,
)

# -------------------------------------------------------------
# 2. Custom G-Eval: Ombudsman Appeal Persuasiveness & Regulatory Rigor
# -------------------------------------------------------------
appeal_quality_metric = GEval(
    name="Ombudsman Appeal Legal Rigor",
    criteria=(
        "Assess whether the draft appeal: (1) cites the exact policy sub-clause and exception, "
        "(2) references specific clinical reports and treatment duration, and (3) adheres to formal Insurance Ombudsman standards."
    ),
    evaluation_params=[
        LLMTestCaseParams.INPUT,
        LLMTestCaseParams.ACTUAL_OUTPUT,
        LLMTestCaseParams.EXPECTED_OUTPUT,
    ],
    threshold=0.80,
)

# -------------------------------------------------------------
# 3. Execution Pipeline for Medical Necessity (G7 Benchmark)
# -------------------------------------------------------------
def run_medical_necessity_evaluation(golden_dataset_path: str):
    with open(golden_dataset_path, "r") as f:
        test_data = json.load(f)

    test_cases = []
    faithfulness_metric = FaithfulnessMetric(threshold=0.95)
    context_recall_metric = ContextualRecallMetric(threshold=0.90)

    for item in test_data:
        # Run agent pipeline to get actual outputs
        # actual_output, retrieved_context = medical_necessity_pipeline.run(item["input"])
        
        tc = LLMTestCase(
            input=item["raw_input_narrative"],
            actual_output=item["pipeline_actual_output"],
            expected_output=item["ground_truth_verdict_and_summary"],
            retrieval_context=item["retrieved_policy_and_clinical_context"],
            context=item["case_facts"],
        )
        test_cases.append(tc)

    # Execute DeepEval test suite
    results = evaluate(
        test_cases=test_cases,
        metrics=[
            faithfulness_metric,
            context_recall_metric,
            toulmin_argument_metric,
            appeal_quality_metric,
        ],
    )
    return results

if __name__ == "__main__":
    print("Ready to execute 3-tier DeepEval test suite.")
